Team sync

Connect a free Supabase project so your whole team shares one candidate database: everyone sees the same results, and duplicate detection works across teammates.
Step 1 — One-time setup (any teammate does this once)
Create a free project at supabase.com → open SQL Editor → paste & run: 
create table if not exists candidates (
  hash text primary key,
  name text,
  file_name text,
  score_data jsonb,
  screened_by text,
  created_at timestamptz default now()
);
alter table candidates enable row level security;
create policy "team_all" on candidates
  for all using (true) with check (true);
alter table candidates
  add column if not exists notes jsonb default '[]';
alter table candidates
  add column if not exists stage text default 'NEW';
Step 2 — Connect (every teammate pastes the same two values)
Find both under Project Settings → API
Notes: the anon key is safe-ish for a small internal team but anyone holding it can read/write the table. For wider use, tighten the RLS policy or add Supabase Auth later.
